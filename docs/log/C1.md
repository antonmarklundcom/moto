# C1 — Link pass, sitemaps, robots, nav

## Built
- `/sitemap.xml` (index) + `/sitemaps/<segment>.xml`: `listings-N` (≤ 5,000), `brands`, `models`, `categories`, `cities`, `dealers`, `pages` (`/motos`, en-cuotas, nuevas/usadas, crosses), `content` (guides + content pages). Each URL passes the same A2 function its page uses, in the current `SITE_NOINDEX` mode. `true` → empty index; `content` → only `content.xml`. `lastmod` comes from real `updated_at` values or is omitted. No priority/changefreq. A segment with no URLs → 404 and it is left out of the index.
- `/robots.txt` per §3.4 plus `/mi-aviso/`, `/gracias`, `/aviso/*/compartir`. The spec's `/publicar/exito` is `/publicar/listo` in the code. `Sitemap:` comes from `SITE_URL`.
- Main nav: Motos · Financiación · Comercios · Cómo funciona. No threshold-dependent page is in it.
- Link-pass wishes:
  - `?marca=x&modelo=y` → `/motos/x/y` (B1/B2).
  - `paths.manage()` and `paths.thanks`, used by moderation and `/mi-aviso` (B4/B10/A4).
  - `Price` shows "Desde X/mes" when there's a cuota without entrega (B3).
- `KNOWN-ISSUES.md` promoted from all phase logs.

## Decisions
- `pages.xml` is a segment of its own: §7 doesn't list `/motos`, en-cuotas, condition or crosses, but they are indexable pages under §2.1.
- `/terminos` and `/privacidad` stay out of `content.xml`, because they are fixed `noindex` until they have real text.
- robots.txt does not block `/terminos`/`/privacidad` (B10 wish). Blocking them would hide their `noindex`, and §3.4 says the same about filters.
- Skipped:
  - The guide link from the listing page (B3): the guide is still a draft, so the link would be a 404.
  - `DEFAULT_LISTING_TTL_DAYS` to a pure module (B10): the copy doesn't need it yet.
  - "Reporte y stock" (B8) and `model_raw` in moderation: both already existed.

## Known issues
- Sitemaps are computed per request with a 1 h cache header. There's no daily regeneration job (fine at this volume).

Verification: `npm run verify` green. The sitemap integration test loads every URL through its own page loader in the three modes (6/6).
