## Decisions
- **Escalado** (`docs/decisions-needed.md`, B3): la matriz de A1 no deja pausar al sistema. La regla está cableada; hoy devuelve `blocked`, loguea y la publicación sigue publicada. Con la opción A es un cambio de una línea en `state.ts` + el test.
- Redirecciones con `permanentRedirect` (308, permanente como 301 para buscadores): una página de Next no puede elegir 301.
- Borrada → 404 en vez de 410: una página de App Router no puede responder 410. Link-pass: 410 desde `middleware.ts` (A1) o un route handler.
- Endpoints propios comparan Origin con el host del pedido y responden Location relativa (no con SITE_URL).

## Known issues
- `/api/telefono` y `/api/leads` (A4) comparan Origin con SITE_URL: fallan si el sitio se sirve con otro host/puerto que SITE_URL (E2E local, staging mal configurado). El E2E lo rodea sólo para ese pedido. Link-pass/C2.
- `Price` (A2) muestra "Precio no informado" si hay cuota sin entrega (`hasFinancingData` exige entrega): pasa con stock importado sin `entrega_gs`. C1/C2.
- `/financiacion?aviso=` y la página de comercio las construye B5; el modelo (redirección > 12 meses) B2.
