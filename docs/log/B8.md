# B8 — Stock import & dealer ops

## Built
- `src/lib/import/`: CSV propio (RFC 4180, BOM, CRLF, `;` de Excel, Latin-1), columnas en español con alias (`columns.ts`), `validateRow` puro contra el catálogo (checklist automatizable de T&S §3: marca/modelo del catálogo, contado o esquema completo, ciudad, teléfono y G-3, sin contacto en título/descripción, G-4, bloque de autorización ADR-12), `buildPlan` (crear / actualizar / sin cambios / rechazar con motivo, huella del plan), `apply.ts` (vista previa sin escribir; aplicar rehace el plan y sólo sigue si la huella coincide).
- Upsert idempotente por `(dealer_id, external_ref)` (clave sin mayúsculas, como el UNIQUE). Nuevas nacen `pending_review` + `activity_log imported`; cambios → `import_updated` (+ `price_changed`). Modelo desconocido/inactivo → sin `model_id`, `model_raw` y una `model_suggestions` pendiente; re-importar no deshace un mapeo hecho en Catálogo.
- `publish.ts`: `auto_approve` del comercio → `transition(approve)` con actor sistema; usada con sólo foto de catálogo no se publica sola.
- Fotos: nombre empieza con la referencia (la más larga, con separador), `catalogo` en el nombre = foto de catálogo; pipeline de A3; misma foto dos veces no se duplica; lector `.zip` propio (stored/deflate, tope anti zip-bomb).
- G-6 `reconfirmStock` + mensaje para WhatsApp con las referencias publicadas; G-14 `dealerReport` (vistas/clics sin bots, leads de financiación sin spam, sólo de sus motos, rango `[from,to)`) + texto de §7.
- Admin: `/admin/importar` (planilla modelo descargable, ayuda por columna, vista previa → confirmar, cargador de fotos/carpeta de a una, lista de comercios), `/admin/comercios/[id]/reporte` (reporte con rango de fechas + copiar; reconfirmar sólo admin/moderación; un dealer ve sólo el suyo).
- CLI `npx tsx scripts/import-dealer-stock.ts <csv> [--comercio slug] [--fotos carpeta|zip] [--apply]` (dotenv primero, vista previa por defecto; se relanza con `--conditions=react-server` para `server-only`).
- Demo: `npm run fixtures && npx tsx scripts/import-dealer-stock.ts docs/templates/demo/stock-demo.csv --apply` → 30 creadas y publicadas; segunda corrida 30 sin cambios.

## Decisions
- Import no toca las filas sin cambios (tampoco `last_verified_at`): reconfirmar es la acción explícita G-6. Crear/actualizar sí fija `last_verified_at`.
- Modo demo (guarda ADR-24 en verde): comercios `dev-` sin fecha de autorización se aceptan con su nota `[DEV]`; se les activa `auto_approve` (logueado `dev_auto_approve`) y cada moto demo recibe el marcador `dev-fixtures/placeholder-1.png`. Con la guarda en rojo (también `next start`, NODE_ENV=production) las filas `DEV-` se rechazan con el motivo.
- Usada sin `estado_documentacion` → `no_declara` con aviso; sólo cuota → `has_financing_only` con aviso; piso de precio Gs. 1.000.000 y cuota Gs. 50.000 (`precio_irreal`).
- Zip sólo por CLI: el middleware del panel corta cuerpos > 10 MB. El admin sube fotos de a una (≤ 10 MB) con Origin = mismo host.
- Sin edición de `package.json` (lane 2): la CLI va con `npx tsx`.
