## Decisions
- `job_runs.lock_key` (UNIQUE, NULL when idle) added to G-8's table: an atomic lock without `GET_LOCK` on a pooled connection. Recorded in ADR-17.
- Landline pattern: area code not starting with 9, 8–9 national digits `[VERIFICAR: CONATEL numbering plan]`.
- Idempotency hour bucket is UTC. `publicRef` alphabet drops 0/O/1/I/L (31 chars).
- `upgrade-insecure-requests` only when `SITE_URL` is https (so `next start` on localhost works for E2E).
- Lane 2 cross-link wishes go in each phase log ("Link-pass wishes"), not in `docs/decisions-needed.md` (that file stays owner-only; no merge conflicts between parallel phases).
- Admin section `actividad` (ADMIN_SPEC §12) was unassigned: A1 stubs it, B9 owns it. `intro_html` editing lives only in B10; B7 links to it. "Block phone" is Backlog (needs table + lawyer). B2 deletes `src/app/page.tsx`.
- Watcher never merges (no CI; it re-spawns the phase, which re-runs verify and merges). Stops after 24 h, not 10 firings.
