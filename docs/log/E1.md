# E1 — Design pass (ADR-15)

## Built
- Shared tokens in `src/components/public/styles.ts`: slate ink on a light background, orange brand accent, green primary action, and shared `fieldClass`, `labelClass`, `surface` and `sectionTitle` classes. Transitions only run under `motion-safe`.
- **Header:** sticky, text wordmark (no image logo: nothing to license, nothing to load). The nav scrolls horizontally on mobile.
- **Footer:** dark.
- **Home:** dark hero with the cuota search on a translucent panel.
- **Listings:** card grid with hover shadow and pill badges.
- **Listing page:** sticky price/contact card on desktop, and a full-width main photo.
- **`/motos` filters:** cuota and entrega come first. Tipo, condición and price moved into "Más filtros", which opens by itself when one of them is applied (B1 known issue).
- Headings unified: h1 `extrabold`, h2 `text-xl bold`.

## Decisions
- No webfont and no component library: the system font stack keeps LCP where it was.
- No change to structure or copy, apart from one decorative eyebrow on the home ("Motos en Paraguay"). No new client JS.
- Admin not restyled (ADR-15: the admin isn't polished in this pass).

## Measurements after the pass (local build)
- Lighthouse mobile: `/` 99, `/motos` 98, model 99. Accessibility 100 everywhere, CLS 0.
- axe: 0 critical/serious. E2E 55/55.
