## Decisions

- **Network limitation, logged not escalated** (`BUILD_PLAN.md` §4.5, degrade
  gracefully): `WebFetch` was blocked for every domain tried this session,
  including non-Paraguayan ones (Wikipedia) — confirmed via
  `/root/.ccr/README.md` as an egress-policy block of this session, not a
  site-side block. This is a tooling limitation, not an escalation-checklist
  item or missing credential, so the session kept going with `WebSearch`
  only. Documented prominently in `catalog.md` §0 and `competitors.md` so the
  next session with different network access re-verifies before B8 imports
  real stock.
- Kept `cg-150-titan` and `cb-125` inactive rather than guessing a
  replacement: the DIESA-sourced ads confirm `CG 110` and `CB 500X` instead,
  which are different enough (displacement, segment) that renaming the
  existing slug's display name would have been a guess, not a confirmation.
  Added new rows instead, per ADR-11.
- Did not add Star's third-party-sourced models (SK 110, A1 110, DAX 110, NK
  150, NT 150, "150 X") — those only appeared in resale/Clasipar listings,
  not `star.com.py` product pages, which is a lower bar than the two that
  were added.
